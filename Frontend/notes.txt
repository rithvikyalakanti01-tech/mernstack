1. <!DOCTYPE html>
---
Purpose: Declares the document type as HTML5
Syntax: <!DOCTYPE html>

Attributes: None (Declaration only)

Notes:
  • Must be the first line in an HTML document
  • Case-insensitive
  • Tells browsers this is an HTML5 document
  • Without it, browsers may enter "quirks mode"


---
2. <html>
---
Purpose: Root element that wraps all content in an HTML page

Attributes:
  lang          - Specifies language (e.g., "en", "es", "fr")
  dir           - Text direction: ltr (left-to-right) | rtl (right-to-left)
  xmlns         - XML namespace (for XHTML)
  Global Attributes: id, class, style, title, data-*, etc.

Example:
  <html lang="en" dir="ltr">
    ...
  </html>

Notes:
  • Parent element of <head> and <body>
  • Always include lang attribute for accessibility and SEO
  • Helps screen readers and translation services


---
3. <head>
---
Purpose: Contains metadata, title, links, and other non-visible information

Attributes:
  Global Attributes: id, class, style, etc.

Child Elements:
  <title>       - Page title (required)
  <meta>        - Metadata
  <link>        - External resources (CSS, icons)
  <style>       - Internal CSS
  <script>      - JavaScript code or links
  <base>        - Base URL for relative links

Example:
  <head>
    <title>Page Title</title>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link rel="stylesheet" href="style.css">
  </head>

Notes:
  • Content is NOT displayed on page
  • Should contain exactly one <title>
  • Meta tags critical for SEO and mobile responsiveness


---
4. <title>
---
Purpose: Sets the page title (shown in browser tab and search results)

Attributes:
  Global Attributes: id, class, style, etc.

Example:
  <title>Welcome to My Website</title>

Notes:
  • Required element
  • Keep 50-60 characters for search results
  • Should be unique and descriptive
  • Critical for SEO


---
5. <body>
---
Purpose: Defines the main visible content of the page

Attributes:
  onload        - JavaScript when page finishes loading
  onunload      - JavaScript when user leaves page
  onbeforeunload - JavaScript before page unloads
  Global Attributes: id, class, style, etc.

Deprecated Attributes (Use CSS instead):
  background    - Background image
  bgcolor       - Background color
  text          - Text color
  link          - Link color
  alink         - Active link color
  vlink         - Visited link color

Example:
  <body>
    <header>...</header>
    <main>...</main>
    <footer>...</footer>
  </body>

Notes:
  • Only one <body> per document
  • All visible content goes here
  • Use CSS for all styling


---
6. <base>
---
Purpose: Sets a base URL for all relative links in the document

Attributes:
  href          - Base URL (required)
  target        - Default target for links: _blank | _self | _parent | _top
  Global Attributes: id, class, style, etc.

Example:
  <base href="https://example.com/pages/">
  <base href="https://example.com/" target="_blank">

Notes:
  • Must be in <head>
  • Only one <base> per document
  • Affects all relative URLs

7. <meta>
---
Purpose: Provides metadata about the HTML document

Attributes:
  charset       - Character encoding (e.g., "UTF-8")
  name          - Metadata name (description, keywords, author, viewport, etc.)
  content       - Content value for the metadata
  http-equiv    - HTTP header equivalent (refresh, content-type, etc.)
  property      - For Open Graph and other properties
  Global Attributes: id, class, style, etc.

Common Examples:
  <!-- Character encoding -->
  <meta charset="UTF-8">
  
  <!-- Mobile responsiveness -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  
  <!-- Page description (SEO) -->
  <meta name="description" content="Brief description of page">
  
  <!-- Keywords (SEO) -->
  <meta name="keywords" content="keyword1, keyword2, keyword3">
  
  <!-- Author -->
  <meta name="author" content="Author Name">
  
  <!-- Robots (SEO) -->
  <meta name="robots" content="index, follow">
  
  <!-- Open Graph (Social Media) -->
  <meta property="og:title" content="Title">
  <meta property="og:description" content="Description">
  <meta property="og:image" content="image.jpg">
  <meta property="og:url" content="https://example.com">
  
  <!-- Refresh page -->
  <meta http-equiv="refresh" content="5">
  
  <!-- Compatibility mode -->
  <meta http-equiv="X-UA-Compatible" content="IE=edge">

Notes:
  • Multiple <meta> tags allowed
  • Critical for SEO and mobile
  • Social media uses Open Graph meta tags


---
8. <link>
---
Purpose: Links external resources like stylesheets, icons, and other documents

Attributes:
  href          - URL of the resource (required)
  rel           - Relationship to current document (required)
  type          - MIME type of resource
  media         - Media type for stylesheet (e.g., "screen", "print")
  sizes         - Icon sizes (for rel="icon")
  hreflang      - Language of linked resource
  crossorigin   - CORS setting: anonymous | use-credentials
  integrity     - Subresource integrity check
  Global Attributes: id, class, style, etc.

Common rel values:
  stylesheet    - CSS stylesheet
  icon          - Website favicon
  alternate     - Alternate version
  prev/next     - Previous/next page
  canonical    - Preferred version of page
  preload       - Preload resource
  prefetch      - Prefetch resource
  dns-prefetch  - Prefetch DNS

Examples:
  <!-- CSS Stylesheet -->
  <link rel="stylesheet" href="style.css">
  
  <!-- Favicon -->
  <link rel="icon" href="favicon.ico">
  
  <!-- Apple Touch Icon -->
  <link rel="apple-touch-icon" href="apple-icon.png">
  
  <!-- Canonical URL (SEO) -->
  <link rel="canonical" href="https://example.com/page">
  
  <!-- Preload font -->
  <link rel="preload" href="font.woff2" as="font" crossorigin>

Notes:
  • Self-closing tag
  • Must be in <head>
  • Multiple <link> tags allowed
  • Critical for styling and SEO

9. <h1> to <h6>
---
Purpose: Define headings from most important (h1) to least important (h6)

Attributes:
  Global Attributes: id, class, style, title, data-*, etc.

Example:
  <h1>Main Page Heading</h1>
  <h2>Section Heading</h2>
  <h3>Subsection Heading</h3>
  <h4>Minor Heading</h4>
  <h5>Very Minor Heading</h5>
  <h6>Least Important Heading</h6>

Notes:
  • h1 should appear once per page
  • Use for structure and SEO, not for styling
  • Screen readers use headings for navigation
  • Never skip levels (e.g., h1 to h3)
  • Proper hierarchy improves accessibility

40. <a>
---
Purpose: Creates hyperlinks to pages, sections, email, or phone

Attributes:
  href          - URL or path to link to (required)
  target        - Where to open: _blank | _self | _parent | _top | framename
  title         - Tooltip text on hover
  download      - Downloads file instead of navigating
  rel           - Relationship: nofollow | noopener | noreferrer | etc.
  type          - MIME type of linked resource
  hreflang      - Language of linked resource
  ping          - URLs to notify on link click
  Global Attributes: id, class, style, data-*, etc.

Common rel values:
  nofollow      - Don't follow link (for SEO)
  noopener      - Don't give access to window object (security)
  noreferrer    - Don't send referrer info
  external      - Link to external site
  help          - Link to help content
  license       - Link to license
  next/prev     - Next/previous page

Examples:
  <!-- Simple link -->
  <a href="https://example.com">Visit Example</a>
  
  <!-- New tab -->
  <a href="page.html" target="_blank" rel="noopener noreferrer">Link</a>
  
  <!-- Jump to section -->
  <a href="#section-id">Jump to Section</a>
  
  <!-- Email link -->
  <a href="mailto:email@example.com">Email Me</a>
  
  <!-- Phone link -->
  <a href="tel:+1-555-123-4567">Call Me</a>
  
  <!-- Download file -->
  <a href="document.pdf" download>Download PDF</a>
  
  <!-- File with custom name -->
  <a href="file.pdf" download="custom-name.pdf">Download</a>

Notes:
  • Always use rel="noopener noreferrer" with target="_blank"
  • mailto: protocol for email links
  • tel: protocol for phone links
  • # for same-page section links
  • Security-critical attribute: rel

42. <img>
---
Purpose: Displays an image on the page

Attributes:
  src           - Image URL or path (required)
  alt           - Alternative text for screen readers (required)
  title         - Tooltip text on hover
  width         - Image width in pixels or percentage
  height        - Image height in pixels or percentage
  loading       - Lazy loading: lazy | eager | auto
  decoding      - Decoding: auto | sync | async
  srcset        - Multiple images for different resolutions
  sizes         - Image sizes for responsive images
  usemap        - Links to <map> for image maps
  ismap         - Server-side image map indicator
  crossorigin   - CORS setting: anonymous | use-credentials
  Global Attributes: id, class, style, data-*, etc.

Examples:
  <!-- Basic image -->
  <img src="image.jpg" alt="Description of image" width="300" height="200">
  
  <!-- Responsive image -->
  <img src="image.jpg" alt="Description" 
       srcset="image-small.jpg 480w, image-medium.jpg 800w, image-large.jpg 1200w"
       sizes="(max-width: 600px) 100vw, (max-width: 1200px) 50vw, 33vw">
  
  <!-- Image map -->
  <img src="map.jpg" alt="Map" usemap="#mymap">

Notes:
  • Self-closing tag
  • alt text is critical (SEO and accessibility)
  • Always specify width and height
  • Prevents layout shift
  • Supported formats: JPEG, PNG, GIF, WebP, SVG
  • Use srcset for responsive images

43. <picture>
---
Purpose: Container for multiple image sources (responsive/format-specific)

Attributes:
  Global Attributes: id, class, style, data-*, etc.

Child Elements:
  <source>      - Image sources with conditions
  <img>         - Fallback image (required)

Example:
  <picture>
    <source media="(max-width: 600px)" srcset="small.jpg">
    <source media="(max-width: 1200px)" srcset="medium.jpg">
    <source srcset="large.jpg" type="image/jpeg">
    <img src="fallback.jpg" alt="Description">
  </picture>

Notes:
  • Requires fallback <img>
  • Browser picks first matching source
  • Supports art direction
  • Better than img srcset for complex scenarios

45. <audio>
---
Purpose: Embeds audio content with playback controls

Attributes:
  src           - Audio file URL (alternative to <source>)
  controls      - Shows play/pause/volume controls
  autoplay      - Starts playing automatically
  loop          - Repeats after finishing
  muted         - Mutes by default
  preload       - What to load: none | metadata | auto
  crossorigin   - CORS setting: anonymous | use-credentials
  Global Attributes: id, class, style, data-*, etc.

Example:
  <audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    <source src="audio.ogg" type="audio/ogg">
    Your browser does not support audio.
  </audio>

Notes:
  • Contains <source> elements
  • Supports MP3, WAV, OGG formats
  • autoplay may require muted
  • Browsers may block autoplay

85. <script>
---
Purpose: Embeds or references JavaScript code

Attributes:
  src           - External JavaScript file URL
  type          - Script type (default: text/javascript)
  async         - Download in background, execute immediately
  defer         - Download in background, execute after page loads
  module        - Treat as JavaScript module
  nomodule      - Script for browsers without module support
  integrity     - Subresource integrity check
  crossorigin   - CORS setting: anonymous | use-credentials
  Global Attributes: id, class, style, data-*, etc.

Examples:
  <!-- Inline script -->
  <script>
    console.log('Hello, World!');
  </script>
  
  <!-- External script -->
  <script src="script.js"></script>
  
  <!-- Async (download and execute immediately) -->
  <script src="script.js" async></script>
  
  <!-- Defer (download, then execute after page loads) -->
  <script src="script.js" defer></script>
  
  <!-- Module -->
  <script type="module" src="module.js"></script>

Notes:
  • Can be in <head> or <body>
  • defer recommended for <head>
  • async for independent scripts
  • Security: src over inline

  Global Attributes: id, class, style, data-*, etc.

Example:

      font-family: Arial, sans-serif;

89. <template>

  Global Attributes: id, class, style, data-*, etc.

90. <embed>
---
Purpose: Embeds external resources (Flash, plugins)

Attributes:
  src           - Resource URL (required)
  type          - MIME type
  width         - Width
  height        - Height
  Global Attributes: id, class, style, data-*, etc.

Example:

Notes:

  • Limited use (Flash is deprecated)

91. <object>
---
Purpose: Embeds multimedia content or external documents

Attributes:
  data          - Resource URL
  type          - MIME type
  width         - Width
  height        - Height
  name          - Name for form submission
  usemap        - Links to <map> for image map
  form          - Associates with form by id
  classid       - Class identifier
  codetype      - Codetype
  codebase      - Base URL for code
  Global Attributes: id, class, style, data-*, etc.

Example:
  <object data="document.pdf" type="application/pdf" width="400" height="600">
    <p>PDF could not be displayed.</p>
  </object>

Notes:
  • More flexible than <embed>
  • Can contain fallback content
  • Complex attributes
  • Limited browser support

92. <param>
---
Purpose: Defines parameters for <object> element

Attributes:
  name          - Parameter name (required)
  value         - Parameter value (required)
  type          - MIME type
  valuetype     - Value type: data | ref | object
  Global Attributes: id, class, style, data-*, etc.

Example:
  <object data="video.swf">
    <param name="autoplay" value="true">
    <param name="loop" value="true">
  </object>

Notes:
  • Self-closing tag
  • Child of <object>
  • Rarely used (Flash deprecated)


---
93. <iframe>
---
Purpose: Embeds another HTML document in a frame

Attributes:
  src           - Document URL
  title         - Accessibility title (recommended)
  width         - Frame width
  height        - Frame height
  frameborder   - Border: 0 | 1 (deprecated, use CSS)
  scrolling     - Scrolling: yes | no | auto (deprecated, use CSS)
  name          - Frame name (for target links)
  sandbox       - Security restrictions (allow-scripts, allow-same-origin, etc.)
  allow         - Feature permissions
  referrerpolicy - Referrer policy
  loading       - Lazy loading: lazy | eager
  crossorigin   - CORS setting: anonymous | use-credentials
  Global Attributes: id, class, style, data-*, etc.

Examples:
  <!-- Basic iframe -->
  <iframe src="page.html" width="400" height="300" title="Embedded page"></iframe>
  
  <!-- YouTube video -->
  <iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID"></iframe>
  
  <!-- With sandbox -->
  <iframe src="untrusted.html" sandbox="allow-scripts"></iframe>
  
  <!-- With loading -->
  <iframe src="page.html" loading="lazy"></iframe>

Notes:
  • Separate document context
  • sandbox for security
  • Use title for accessibility
  • Can be targeted by links

================================================================================
GLOBAL ATTRIBUTES (Applicable to Most Elements)
================================================================================

---
id
---
Purpose: Unique identifier for an element
Value: Unique string (case-sensitive)
Example: <div id="main-container">...</div>
Notes: Used by CSS and JavaScript for targeting

---
class
---
Purpose: CSS class(es) for styling or selection
Value: Space-separated class names
Example: <div class="container primary">...</div>
Notes: Multiple classes allowed

---
style
---
Purpose: Inline CSS styling
Value: CSS declarations
Example: <p style="color: blue; font-size: 16px;">Text</p>
Notes: Lower specificity than stylesheets

---
title
---
Purpose: Tooltip text shown on hover
Value: Text string
Example: <a href="#" title="Tooltip text">Link</a>
Notes: Appears on hover

---
lang
---
Purpose: Language of element content
Value: Language code (e.g., "en", "es", "fr")
Example: <p lang="es">¡Hola!</p>
Notes: Important for accessibility

---
dir
---
Purpose: Text direction
Value: ltr | rtl | auto
Example: <p dir="rtl">This text runs right to left</p>
Notes: For multilingual content

---
data-*
---
Purpose: Custom data attributes
Value: Any string
Example: <div data-user-id="12345" data-role="admin">...</div>
Notes: Accessed via JavaScript dataset API

---
contenteditable
---
Purpose: Makes element editable
Value: true | false | inherit
Example: <div contenteditable="true">Edit this text</div>
Notes: Requires JavaScript for persistence

---
tabindex
---
Purpose: Tab order for keyboard navigation
Value: Integer (-1 to 32767)
Example: <button tabindex="1">First</button>
Notes: -1 removes from tab order

---
hidden
---
Purpose: Hides element from display
Value: Boolean attribute (no value needed)
Example: <p hidden>This is hidden</p>
Notes: Display: none equivalent

---
draggable
---
Purpose: Enables drag and drop
Value: true | false | auto
Example: <img draggable="true" src="image.jpg">
Notes: Requires JavaScript handlers

---
spellcheck
---
Purpose: Spell checking
Value: true | false | default
Example: <textarea spellcheck="true"></textarea>
Notes: Browser-dependent

---
dropzone
---
Purpose: Accepts dragged/dropped files
Value: copy | move | link
Example: <div dropzone="copy">Drop files here</div>
Notes: Part of drag/drop API

---
accesskey
---
Purpose: Keyboard shortcut for element
Value: Single character
Example: <a href="#" accesskey="h">Home</a>
Notes: Alt+key activates (browser-dependent)

---
aria-label
---
Purpose: Accessible label for screen readers
Value: Text description
Example: <button aria-label="Close dialog">×</button>
Notes: For elements without visible labels

---
aria-describedby
---
Purpose: References element that describes this one
Value: Element ID
Example: <input aria-describedby="help">
Notes: For additional accessibility info

---
aria-hidden
---
Purpose: Hides from screen readers
Value: true | false
Example: <span aria-hidden="true">icon</span>
Notes: Different from HTML hidden

---
role
---
Purpose: ARIA role for assistive technology
Value: ARIA role name
Example: <div role="alert">Important message</div>
Notes: Semantic HTML preferred
